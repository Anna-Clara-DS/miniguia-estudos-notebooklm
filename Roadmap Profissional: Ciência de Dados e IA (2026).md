# 🗺️ Roadmap Profissional: Ciência de Dados e IA (2026)

Este guia detalha o caminho das pedras para sair do zero e alcançar o nível de especialista, focando em onde começar e como progredir na carreira de forma sustentável.

---

## 🚀 1. Por onde começar (O "Absolute Zero")

Antes de tocar em Inteligência Artificial, você precisa dominar o alicerce. A matemática é o bicho de sete cabeças que, na verdade, é o seu melhor amigo para entender os algoritmos [4, 5].

### 📚 Cursos Gratuitos Recomendados:
*   **Matemática:** [Khan Academy](https://pt.khanacademy.org/) (Estatística, Álgebra Linear e Cálculo) [6].
*   **Python:** [Curso em Vídeo](https://www.youtube.com/c/CursoemVideo) (Mundos 1, 2 e 3) ou [Data Science Academy](https://www.datascienceacademy.com.br/) (Fundamentos Gratuitos) [7-9].
*   **SQL:** [Alessandro Trovato](https://www.youtube.com/user/alessandrotrovato) no YouTube (SQL Server para o dia a dia) [7].
*   **Introdução:** [ENAP](https://www.enap.gov.br/) (Introdução à Ciência de Dados) [10].

## 🛠️ 2. O que aprender (Hard Skills por Nível)

### 🟢 Nível 1: Alfabetização de Dados
*   **Excel/Google Sheets:** Ainda muito relevante para análises operacionais rápidas [11].
*   **SQL Básico:** Joins, agregações e subconsultas [12].
*   **Visualização:** Power BI ou Tableau (saber criar um dashboard que conte uma história) [8, 11, 13].

### 🟡 Nível 2: Análise Exploratória e Programação
*   **Python para Dados:** Bibliotecas **Pandas** (tabelas), **NumPy** (cálculos) e **Matplotlib/Seaborn** (gráficos) [14-16].
*   **Data Cleaning:** Aprender a tratar valores ausentes (NaN) e outliers, etapa que toma **80% do seu tempo** [17, 18].

### 🔴 Nível 3: Ciência de Dados e Machine Learning
*   **ML Supervisionado:** Regressão (linear/logística) e Classificação (Random Forest, SVM) [19-21].
*   **Deep Learning:** Redes neurais complexas, Visão Computacional e NLP [22-24].

## 💼 3. Com o que começar a trabalhar? (O Pulo do Gato)

A transição de carreira mais eficiente em 2026 é o caminho **Analista -> Cientista -> Engenheiro de IA** [3].

1.  **Primeiro Passo - Estágio em Análise de Dados:**
    *   **Foco:** Gerar insights de dados históricos e criar relatórios [25, 26].
    *   **Por que:** É mais fácil conseguir a primeira vaga, e você aprende a "regra de negócio" da empresa, o que é fundamental para qualquer cientista [2, 27, 28].
2.  **Segundo Passo - Cientista de Dados Júnior:**
    *   **Foco:** Começar a usar Machine Learning para prever o futuro (ex: previsão de churn ou vendas) [25, 29, 30].
3.  **Terceiro Passo - Engenheiro de IA:**
    *   **Foco:** Pegar os modelos do cientista e colocá-los em produção (MLOps) de forma escalável [31-33].

## 📂 5. Construindo seu Portfólio "Nota 10"

O mercado de 2026 valoriza **quem prova que sabe fazer** [42]. Não use o dataset do Titanic; busque problemas reais [43].

*   **Ideia de Projeto 1 (Iniciante):** Dashboard de análise de acidentes de trânsito em uma cidade real (dados abertos) [44, 45].
*   **Ideia de Projeto 2 (Intermediário):** Pipeline automatizado de limpeza de dados em Python que detecta outliers e preenche valores nulos [46].
*   **Ideia de Projeto 3 (Avançado):** Modelo de detecção de fraudes em transações financeiras usando Machine Learning [47, 48].
